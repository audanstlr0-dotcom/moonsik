# 아기 예방접종 수첩

신생아·영유아 예방접종을 **개월 수에 맞춰 알려주고**, **맞았는지 체크**하는 앱입니다.
휴대폰 홈 화면에 설치해서 앱처럼 쓸 수 있는 웹앱(PWA)이고, 인터넷이 없어도 동작합니다.

## 주요 기능

- **생년월일만 입력하면 일정 자동 계산**: 질병관리청 국가예방접종 표준일정(BCG, B형간염, DTaP, 폴리오, Hib, 폐렴구균, 로타바이러스, MMR, 수두, A형간염, 일본뇌염, 인플루엔자, Tdap, HPV)을 기준으로 차수별 권장 날짜와 권장 기간을 계산합니다.
- **접종 체크**: 동그라미를 누르면 완료로 표시됩니다. 항목을 누르면 접종일과 메모(병원, 백신 제품명)를 기록할 수 있습니다.
- **상태 표시**: `지금 접종 시기` · `곧 접종(2주 이내)` · `권장 시기 지남` · `예정` · `접종 완료`
- **이전 차수 기준 일정**: A형간염 2차, 일본뇌염 2·3차처럼 이전 접종일을 기준으로 하는 차수는 실제 접종일을 입력하면 다시 계산됩니다.
- **백신 종류 선택**: 로타바이러스(로타릭스 2회 / 로타텍 3회), 일본뇌염(불활성화 5회 / 생백신 2회)
- **알림**
  - 앱을 열 때 접종 시기가 된 항목을 알림으로 보여줍니다(하루 한 번).
  - **캘린더 내보내기(.ics)**: 남은 일정을 휴대폰·구글 캘린더에 넣으면 앱을 열지 않아도 접종 전날 알림을 받을 수 있습니다.
- **여러 아이 관리**, 백업 파일 저장/불러오기, 다크 모드

모든 데이터는 기기 안(브라우저 저장소)에만 저장되고 외부로 전송되지 않습니다.

## 실행 방법

Node.js 18 이상이 필요합니다(설치할 패키지 없음).

```bash
npm start      # http://localhost:8080 에서 실행
npm test       # 일정 계산 로직 테스트
```

## 휴대폰에서 쓰기

앱 주소: **https://audanstlr0-dotcom.github.io/moonsik/**

1. 휴대폰 브라우저로 위 주소를 엽니다.
2. 홈 화면에 추가합니다.
   - **아이폰**: Safari 아래쪽 공유 버튼(□↑) → **홈 화면에 추가**
   - **안드로이드**: Chrome에서 앱 안의 **설치** 버튼, 또는 ⋮ 메뉴 → **앱 설치 / 홈 화면에 추가**
3. 홈 화면 아이콘으로 열면 일반 앱처럼 전체 화면으로 열리고, 인터넷이 없어도 동작합니다.

> 아이폰은 홈 화면에 추가한 뒤에만 알림을 켤 수 있어요(iOS 16.4 이상).
> 기록은 그 휴대폰에만 저장되니, 폰을 바꿀 때는 설정 → 백업 파일 저장을 이용하세요.

### 배포 (처음 한 번만)

`.github/workflows/pages.yml` 이 기본 브랜치에 push 될 때마다 테스트 후 자동으로 배포합니다.
처음 한 번은 저장소 **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions** 로 바꾼 뒤
**Actions** 탭에서 "Deploy to GitHub Pages" 를 다시 실행(Re-run)하세요.

## 파일 구조

| 파일 | 역할 |
| --- | --- |
| `js/schedule.js` | 백신별 접종 일정 데이터 (일정을 고칠 때는 이 파일만 수정) |
| `js/planner.js` | 생년월일·접종 기록으로 권장일과 상태를 계산 |
| `js/dates.js` | 날짜 계산(개월 덧셈, 생후 개월 수) |
| `js/ics.js` | 캘린더(.ics) 파일 생성 |
| `js/store.js` | 기기 내 저장/불러오기 |
| `js/app.js` | 화면과 동작 |
| `sw.js` | 오프라인 캐시, 알림 클릭 처리 |

## 주의

이 앱의 날짜는 표준일정에 따른 **권장 시기**입니다. 실제 접종은 아이 상태, 백신 제품, 이전 접종 이력에 따라 달라질 수 있으니
소아청소년과 의사와 상담하고 [예방접종도우미](https://nip.kdca.go.kr)에서도 확인하세요.
